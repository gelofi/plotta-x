# This is the PUBLIC version of Plotta.

Plotta-X<br>
Author: gelofi<br>
Version [public]: 5.2

A Discord bot created in Python to automate tasks with matplotlib. Plotta-X offers basic plotting functions such as bar graphs, line plots, and pie charts.<br>
As the free, public version, you may tinker and fork this repository.<br>
Plotta-X only supports matplotlib.

## Plotta
Plotta offers more graphing tools compared to its public official version, Plotta-X.
Unlike this repository, Plotta includes more commands, such as the pandas library, and combining both pandas and matplotlib.
